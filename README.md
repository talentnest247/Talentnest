# TalentNest

**University Skills Marketplace Platform**

Connect students with talented artisans within the UNILORIN community.

## Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Features

- **Student Registration** - Students can sign up and browse services
- **Artisan Registration** - Service providers can register with portfolios
- **Admin Dashboard** - Manage and verify artisan registrations
- **Marketplace** - Browse and book skilled artisans

## User Roles

1. **Students** - Browse and book artisan services
2. **Artisans** - Offer skills and services (requires admin approval)
3. **Admin** - Verify and manage all users

## Admin Access

Admin login: [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
